### Offline maps
- Fixed the phone's offline maps screen crashing when a saved area came from a server area that is also listed.
- Overlapping areas are drawn as one combined outline on the web and the phone; an area's own box shows when you pick it in the downloads list.

### Removing map areas
- Removing an area from the server is about twice as fast and uses several CPU cores.
- Places of interest from a removed area no longer linger as map icons and search results; ones left by earlier removals are cleared automatically after updating.
- The web map no longer keeps showing a removed area's detail until the page is reloaded.
