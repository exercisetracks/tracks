### Offline maps on the phone
- Areas are saved as whole map files instead of tile by tile, so you can keep as much map as your phone has room for — whole states or countries — on its own storage or an SD card.
- Saved areas keep their trails, contours and terrain offline after the server changes; before, a download or delete anywhere on the server could leave them showing only the basemap.
- Downloads keep going with the app closed, show progress in a notification (including while the server builds the area), resume after a dropped connection, and are checked before use.
- Areas saved the old way are moved over automatically on Wi-Fi.
- New "Server only" option: build an area on the server without saving it to the phone.
- A storage bar shows other apps, offline maps and free space; "Download on Wi-Fi only" is in Settings.

### Maps on the server
- Adding a small area takes about a minute instead of 7.7 minutes; removing one takes seconds.
- Each map is stored once instead of twice, and overlapping areas no longer need merging.
- Builds run one at a time and pick up where they left off after a restart.
- Size estimates come back in a fraction of a second and count only what is new.
- One progress bar per download that only moves forward, including the trail-data download.
- Oceans, seas, gulfs and lakes are named on the map.
- National forests and other public land reaching past a downloaded area are no longer left out; existing areas rebuild their trail layer once, automatically.
- Removing an area from the server is admin-only and asks first.

### Phone
- All status — sync, the watch, backups, map downloads and results — appears in one pill at the top; tap it for details.
- Pull to sync works on every page.
- If the watch stops sending its activities and health files, Tracks tells you to restart it.
- Signing out takes effect immediately.
- Connecting to a different server combines the phone's data with the server's instead of deleting the server's.

### Web
- If your encryption key expires, Tracks asks for your password instead of showing empty pages.
- Contour generation no longer runs out of memory on smaller servers.
- The map search box has a single clear button.
